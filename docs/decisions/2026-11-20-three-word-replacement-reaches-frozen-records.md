# 「台帳」「ゲート」「版」の置き換えも、凍結した決定の記録と古い ADR に及ぶ（中身は変えない）

- 日付: 2026-11-20
- 出典: ADR-0040（[adr/0040-kanban-gate-version-words.md](../adr/0040-kanban-gate-version-words.md) 決めたこと 6。オーナー 2026-11-20 が、替える場所を役の名前の置き換えと同じにすることに同意した）
- 覆す: [2026-11-10-word-replacement-reaches-frozen-records.md](2026-11-10-word-replacement-reaches-frozen-records.md) のうち「今回の語だけが例外」（一部。この 3 語の置き換えを例外に足す）と、ADR-0026 決めたこと 10・13 の「本文は当時の記録として残す」（一部。語の置き換えだけ）

「台帳」を kanban に、「ゲート」を gate に、「版」を「バージョン」に替える置き換えは、`docs/decisions.md` の凍結した表の行と、`docs/decisions/`・`docs/adr/` の古いファイルにも及ぶ。古い文書を読んだエージェントが古い語を真似ることを無くし、読み手が読み替えをしなくて済むようにするため。変えてよいのは語だけで、決定の中身・理由・捨てた案・番号・行の順は変えない。オーナーの発言の引用（「」の中）と、当時の識別子をバッククォートで写した所と、`docs/vision.md` と、`CHANGELOG.md` のバージョンごとの節は替えない。置き換えは、ADR の棚卸しの作業と、役の名前の置き換えの同じ場所の作業が済んでから行う。
