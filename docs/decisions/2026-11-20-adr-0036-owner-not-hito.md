# ADR-0036: 役の名前を「人」から「オーナー」に改める

- 日付: 2026-11-20
- 出典: ADR-0036（[adr/0036-owner-not-hito.md](../adr/0036-owner-not-hito.md)。オーナーが Chief Engineer との対話の中で決めた。元はオーナーの発言 2026-11-20「人　っていうのが結構無機質だからオーナーにしようかね」「Andon全体に広げましょう」）

仕事を頼み決断する役を、Andon の文で「人」と書くのをやめ、「オーナー」と書く。「人」は役の名前でないので、役の名前で呼ぶ。ラインの中で頼む・決める・答える・マージする・直す・打つ人間はオーナー 1 人なので、その行いの主や相手を言う「人」は、機械や AI と並べた所でも「オーナー」にする。数え方、熟語、外の人、文書の性質を言う「人が読む」「人用」は「人」のまま残す。役の正式な名前は「セルのオーナー」で、文の中ではどこでも「オーナー」と略す。ファイルや repo のオーナーには、何のオーナーかを必ず付ける。ゲートが PR に書く外向けのコメントでは「メンテナー」と書く。替える範囲は repo の全部で、ADR の本文と決定の記録も語だけ替える。ビジョンの文書と図、オーナーの発言の引用、英語の識別子は替えない。機械が照合する日本語は新しい語で書き、古い語も読む。役を指す形の「人」が戻らないことは検査で守る。価値の仮説は置かない。役をいつも「セルのオーナー」と書く案と、過去の記録を替えない案は捨てた。
