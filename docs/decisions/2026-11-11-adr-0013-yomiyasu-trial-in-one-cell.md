# ADR-0013 の改め: 書き方の細かい決まりを外の skill の yomiyasu に任せられるかを、セル1つで試す

- 日付: 2026-11-11
- 出典: ADR-0013（[adr/0013-short-role-names-and-plain-japanese.md](../adr/0013-short-role-names-and-plain-japanese.md) の決めたこと 16〜23。Chief Engineer の課題 A-0151。オーナーが対話の中で決めた。元は人の言葉 2026-11-11「細々した日本語関連のPromptですが取り除いてYOMIYASU SKILLをいれてみるのは試してみてもよいかもしれません」）

日本語の文の構造を直す外の skill の yomiyasu を、セル1つに入れて試す。セルの外の skill の一覧に1行、セルの指針に指示の1行を書き、パッケージは変えない。通す文は依頼書・wiki のページ・課題の報告の3種類で、会話の返事・`docs/` の文書・PR の説明文には通さない。設定を入れる前の見比べはしない。版は固定しない。Andon の語を yomiyasu から守らず、言い換えられた語は用語集の語を減らす材料にする。3種類を合わせて 30 件通したところで材料をまとめ、人が「パッケージの既定に入れる」「セルだけで続ける」「やめて設定を消す」のどれかを決める。`package/writing.md` は判定まで今のままで、yomiyasu と重なる5行を外すかは判定のあとに決める。Andon に固有の決まり（結論を先に・番号に題を添える・CoS と CE の呼び名など）は残す。`writing.md` を全役に配る課題（切る案 V2・V3）は試しを待たずに進める。決めたこと 8 件・捨てた案・受け入れ条件 13〜15・切る案 Y1〜Y3 は ADR が正。
