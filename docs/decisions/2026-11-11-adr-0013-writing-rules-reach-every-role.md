# ADR-0013 の改め: 「人への書き方」は `package/writing.md` に置き、boot が全役の設定ファイルに入れる

- 日付: 2026-11-11
- 出典: ADR-0013（[adr/0013-short-role-names-and-plain-japanese.md](../adr/0013-short-role-names-and-plain-japanese.md) の決めたこと 8〜15。Chief Engineer の課題 A-0137。オーナーが対話の中で決めた。元は調べる課題 A-0117 の候補 c4・c5 と、人の答え 2026-11-11「はい、Chief Engineer に渡して」）

「人への書き方」の節は、用語集の skill がモデルから呼べない設定のため、どの役にも届いていなかった。節を新しいファイル `package/writing.md` に移し、boot が `environment.md` と並べて Claude の `CLAUDE.md` と Codex の `~/.codex/AGENTS.md` に入れる。語の決まり3つ（CoS・CE と書く・カタカナの語はカタカナのまま・訳語を作らない）も `writing.md` を正にする。語ごとの定義は用語集に残し、`writing.md` に書いたパスで引く（用語集の設定は変えない）。「括弧には識別子だけ」「番号で参照しない」の2行は、「課題は番号（題）で書く」（ADR-0008）とぶつからない形に書き直す（括弧に入れるのは識別子と番号に添える題だけ。番号だけで指さず、同じ返事の2度目からは番号だけでよい）。節に3行足す（読む人は道具の呼び出しを見ていない・つながる考えは段落で・作業中に付けた呼び名を使わない）。skill に残る「番号（題）」の行は `writing.md` を指す1行に縮め、worker skill の報告の書式の括弧を直す。全役に配るのは、CoS skill の行数の上限の直し（A-0123）のマージのあと。決めたこと 8 件・捨てた案・受け入れ条件 7〜12・切る案 V1〜V4 は ADR が正。
