# ADR-0049: オーナーの介在回数を、操作の種類で数える

- 日付: 2026-11-22
- 出典: ADR-0049（[adr/0049-owner-touches-by-kind.md](../adr/0049-owner-touches-by-kind.md)。Chief Engineer の課題。オーナーが対話の中で決めた。元は、一次の指標の介在回数が 7 日で 0 回と出たこと）

`andon measure` の一次の指標「PR あたりのオーナーの介在回数」の数え方を改める。kanban の履歴の書き手（`by`）で見分ける形をやめ、オーナーの操作を 3 種で数える。マージは gate の記録にマージの印が無い PR、判断は「誰が決めたか」の印が `owner` の答え、オーナーの課題は問いを持たずに片付いた `who: person` の課題である。印は kanban の問いの任意のキー `decidedBy` で、`kanban answer --decided-by` で答えを書く者が書く。印の無い答えは介在回数に入れず、答えを決めた者ごとの数を別に出す。出力に内訳を足し、出力のバージョンを 2 に上げる。指標そのもの（一次は PR あたりのオーナーの介在回数。2026-11-07）は変えない。2026-11-09 の「新しい記録は足さない」は、今ある記録に任意のキーを 1 つ足す点だけ改める。端末で打った文、Chief Engineer のダイアログへの答え、PR の上のコメントと commit は数えない。中身・理由・捨てた案は ADR が正。
