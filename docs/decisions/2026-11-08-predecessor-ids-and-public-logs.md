# 前身の台帳の番号 Y-<数> は残して README で説明し、公開の検査はログに当たりの中身を出さない

- 日付: 2026-11-08
- 出典: 人（2026-11-08「Andon を public にする」）・タスク Y-217

public にするにあたり 2 つを決めた。

- **Y-番号**: ADR・decisions.md・CHANGELOG・commit メッセージに残る `Y-<数>` は、前身の仮設の工場の台帳の番号。履歴と過去の行は書き換えず、[README.md](../../README.md) に「この repo の課題の id（`A-0001` の形）とは別物」と 1 行書く。
- **公開の検査**: public の repo では Actions のログも公開される。`tests/public.sh` は当たりを「`[denylist]` または `[secret]` ＋ ファイル名:行番号」だけ出し、行の中身と当たった語は出さない。終了コードと ok の行は変えない。`tests/public-selftest.sh` が、語と中身が出力に出ないことを確かめる。

捨てた案:

- **過去の文書の Y-番号を消す**: 履歴を書き換えないと決めたため。
