# 台帳の形式も schema/ が正にし、ledger.md は schema を言葉で説く

- 日付: 2026-11-14
- 出典: 課題 A-0202（A-0118 の見送り）。decisions.md §7 の K2（2026-11-05）の「形式の正は `docs/ledger.md` と `schema/ledger/`」の、2つが食い違ったときの向きを決める

- 台帳の形式の正は `schema/ledger/`（ほかの約束と同じく `schema/` が正。`AGENTS.md`）。`docs/ledger.md` は schema を言葉で説く文書で、食い違えば ledger.md を schema に合わせて直す。
- 前の ledger.md は「schema は this file から作った。食い違えば this file が正」と書いていて、`AGENTS.md` の「約束の正は `schema/`」と逆に読めた。
