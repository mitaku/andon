# ADR-0050: 重い command を外のマシンで回し、定期の仕事を API キーで対話なしに動かす

- 日付: 2026-11-22
- 出典: ADR-0050（[adr/0050-external-compute.md](../adr/0050-external-compute.md)。Chief Engineer の課題。元はオーナーの発言 2026-11-21「このPCでは４つ（＋アルファ）しか動かすのが大変とわかったので、もう少し外部リソースを活用できる仕組みなどを考えておきたい」）

提案の段で、検討の途中までの結果を残した。オーナーが決めたのは範囲だけで、範囲は、外の計算資源を使う仕組みと、対話なしの実行を 1 種類だけ足すことの 2 つである。オーナーは出口で、全体の設計をもう少し検討したいと言い、構造と、借りるマシンと、API キーの置き方と、AI Gateway を通すかの 4 つは決めていない。決まるまで、この ADR から依頼書を切らない。Chief Engineer の案は、担当とレビュアーをセルに残し、担当が打つ検査とビルドだけを、hc の machine として足した外のマシンで走らせる形である。あわせて、サブスクリプションに付く API クレジットを使えるように、ルーチンが足す定期の仕事を、API キーの `claude -p` で起動する道を足す。
