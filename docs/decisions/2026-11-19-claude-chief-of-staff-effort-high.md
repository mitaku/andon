# プロファイル claude と chief-of-staff は --effort high を明示する

- 日付: 2026-11-19
- 出典: 人の決断（2026-11-19）。課題 A-0011（A-0009 の c5・c6）

- `package/templates` の `claude` と `chief-of-staff` の command（`claude` は resume も）に `--effort high` を明示する。別名 `opus` が Opus 5.5 に解けるようになり、モデルの既定が medium になったため。
- ほかのプロファイル（`sonnet`・`fable`・`chief-engineer`・`codex`・`codex-review`・`claude-review`）は変えない。
