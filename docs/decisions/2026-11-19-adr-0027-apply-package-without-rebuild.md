# ADR-0027: 開発中の Andon のパッケージを、イメージを焼き直さずにセルへ当てる

- 日付: 2026-11-19
- 出典: ADR-0027（[adr/0027-apply-package-without-rebuild.md](../adr/0027-apply-package-without-rebuild.md)。Chief Engineer の課題 A-0016。オーナーが対話の中で決めた。元はオーナーの発言 2026-11-19「毎度イメージを焼き直すのは大変なので、イメージを焼き直したら消えたりすることを前提としてもよいので、それぞれのファイルを置き換えれるような仕組みを構築したほうがよさそう」）

Andon を開発するセルで、`origin/main` に含まれる1つの commit から `package/`・`schema/`・`andon`・`kanban` を全部まとめて `/opt/andon` にその場で上書きし、`andon boot` を打ち直して dispatcher を起動し直す道具を持つ。道具は andon の repo の中のスクリプトで、イメージには入れない（利用者のセルには届かない）。当てるのは Chief of Staff（マージのあとに自分の判断で。オーナーに1行で知らせる）とオーナーで、担当は当てない。動いているエージェントは止めず、古い skill のまま動いている端末の一覧を出す。当てた commit・日時・イメージの元の commit を記録し、状態を出す口が main からの遅れを出す。初回にイメージのバージョンを退避し、イメージのバージョンへ戻す口を持つ。`image/` が変わっていたら警告して当てる。上書きはコンテナの作り直しで消え、正はイメージのまま。価値の仮説を置く（見る日 2026-12-03）。マージ前の変更をセル全体に当てること・ファイルを選んで当てること・マージのたびの自動の適用・イメージの備品とホスト側のファイルを届けることは範囲の外。中身・理由・捨てた案は ADR が正。
