# ADR-0013: 役の呼び名を短くし、人に向けた日本語をふだんの言い方に揃える

- 日付: 2026-11-10
- 出典: ADR-0013（[adr/0013-short-role-names-and-plain-japanese.md](../adr/0013-short-role-names-and-plain-japanese.md)。Chief Engineer の課題 A-0035。人が対話の中で決めた）

Chief Engineer の略称は CE（用語集に「略して CE」。文の中では CoS・CE と書き、識別子は変えない）。用語集に「エンジニアリングとビジネスでふだんカタカナで言う語（コスト・プロファイル・テンプレート・コンテキスト・オーナー・ログ・パス）はカタカナのまま。訳語を新しく作らない」の決まりを足し、1行目の「ここにある語だけを使う」は役と部品の語に狭める。直す語は9行（費用→コスト・席→やめる・持ち主→オーナー・逃げ口→フォールバック・文脈→コンテキスト・提供元→プロバイダ・端末の土台→hc・迎える→追加する・起こす→起動する）。範囲は repo の全部（文書・ADR と決定の記録は語だけ・skill・`init/`・`image/`・CLI の出力・Go のコメント・テスト）。用語集に「人への書き方」の節7行（文で書く・1文に1つ・括弧には識別子だけ・番号で参照しない・内輪の語はふだんの言葉に・結論を先に〈BLUF〉・報告と引き継ぎは状況・経緯・見立て・推奨の順〈SBAR〉。コードと人が別の形を求めたときは除く）。CE の問いも ask-one-by-one に揃え1回の返事で1問。確かめ方は語が `tests/words.sh` の grep、文体は人の目。反論で壊れると分かった4語（控え・検査・継ぎ目・条件表）は残す。決めたこと 7 件・やらないこと 8 件・切る案 W1〜W7 は ADR が正。
