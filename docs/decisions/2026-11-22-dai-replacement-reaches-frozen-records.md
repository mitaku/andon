# 「題」の置き換えも、凍結した決定の記録と古い ADR に及ぶ（中身は変えない）

- 日付: 2026-11-22
- 出典: ADR-0048（[adr/0048-title-and-theme-not-dai.md](../adr/0048-title-and-theme-not-dai.md) 決めたこと 8。オーナー 2026-11-22 が、替える範囲を repo の全部にすると選んだ）
- 覆す: [2026-11-10-word-replacement-reaches-frozen-records.md](2026-11-10-word-replacement-reaches-frozen-records.md) のうち「今回の語だけが例外」（一部。この語の置き換えを例外に足す）と、ADR-0026 決めたこと 10・13 の「本文は当時の記録として残す」（一部。語の置き換えだけ）

熟語でない「題」を「タイトル」か「テーマ」に替える置き換えは、`docs/decisions.md` の凍結した表の行と、`docs/decisions/`・`docs/adr/` の古いファイルにも及ぶ。古い文書を読んだエージェントが古い語を真似ることを無くし、読み手が読み替えをしなくて済むようにするため。変えてよいのは語だけで、決定の中身・理由・捨てた案・番号・行の順は変えない。オーナーの発言の引用（「」の中）と、語そのものを挙げた所と、`docs/vision.md` と、`CHANGELOG.md` のバージョンごとの節は替えない。置き換えは、skill と生きている文書の置き換えが済み、開いている Chief Engineer の文書がマージされてから行う。
