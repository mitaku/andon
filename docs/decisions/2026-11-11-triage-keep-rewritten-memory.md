# トリアージの apply は、収集のあとに書き換わった memory を消さずに残す

- 日付: 2026-11-11
- 出典: A-0092 の2回目のレビューの指摘（反映の途中に別のセッションが同じ `.md` を書き換えると、新しい中身まで消え、記録には古い本文しか残らない）。[2026-11-11-triage-kind-memory.md](2026-11-11-triage-kind-memory.md) の「keep 以外の memory を消す」に足す。課題 A-0155

`andon triage apply` は memory のファイルを消す前に、今の本文の sha1 を収集のときの key と照らす。違えば、ファイルと目録の行を残し、記録（`library/triage/<日付>-<id>.json`）のその項目に `memory_kept`（理由）を書き、要約（`.md`）に「消さずに残した memory」の節を出す。apply は止めない。ほかの決定はそのまま当たり、残したファイルは次のトリアージで新しい本文として拾い直す。止めると、すでに台帳に当てた決定（起動した課題・閉じた課題）が途中で切れ、当て直しを人が見ることになるため。
照らしてから消すまでの間（同じプロセスの中の短い間）の書き込みは防がない。
