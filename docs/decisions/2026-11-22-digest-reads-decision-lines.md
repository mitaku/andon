# ダイジェストの決定の行は「機械は Markdown を読まない」の4つ目の例外にし、足した行は文の比べで見分ける

- 日付: 2026-11-22
- 出典: ADR-0044 決めたこと 6 の細部（節 5 の決定の行は、`docs/` の文書の「決めたこと」の節から拾う）の実装。実装の担当が推奨案で決めた。

`andon digest collect` は、代わりに決めたことを次の形で集める（形の正は contract.md §26）。

- contract.md §0 の 1 の例外に4つ目として足す。読むのはオーナーに見せる行だけで、判定には使わない。ほかの3つと同じく、これより広げない。
- 印は太字の中の括弧と、太字のすぐ後ろの括弧の両方で拾う。ADR-0037 決めたこと 3 の書き方は後ろで、ADR-0039 からの文書は中に書いている。
- 差分の + の行をそのまま拾わず、親の文書に同じ文と印の無い行を拾う。1行に本文まで続く決定が多く、+ の行をそのまま拾うと、本文の語を替えただけの PR が古い決定を新しい決定として並べる。
- main は一時の bare の写しに取り直す。手元の origin/main は古いことがあり、期間で切るので、漏らした行は次のダイジェストにも載らない。checkout の refs を動かす案は、collect は読むだけという ADR-0044 決めたこと 3 に合わないので捨てた。
- トリアージの記録には当てた時刻が無いので、課題の片付けの時刻で期間を切る。ファイルの更新時刻は、写しや復元で動くので使わない。
- 範囲の問いの答えは、役の端末から書かれたものだけを載せる。オーナーが打った文をセルの外へ出さないため（決めたこと 6 の細部）。
