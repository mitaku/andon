# Chief Engineer は事実を自分で読み、サブエージェントに回すのは広い探索だけにする

- 日付: 2026-11-11
- 出典: 人 2026-11-11 のメンテナンス（以前のモデル向けの指示の見直し）。A-0117 の候補 c1、A-0119

Chief Engineer の skill と design.md §1.8 の「読む」は、環境にある事実をいつも副エージェントに取りに行かせる形だった。Chief Engineer は Fable で動き、委任をいつもの指示にすると必要より多く副エージェントを起こす。事実は Chief Engineer が自分で読む。広く探して結論だけ要るとき（多くのファイル・場所を掃く）に限り、読むだけの副エージェントに回してよい。数回の読みで済むものは回さない。反論を走らせる段（§1.8 の 6）の副エージェントは別の文脈が要るので変えない。
