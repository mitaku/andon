# 役の名前の置き換え（人→オーナー）も、凍結した決定の記録と古い ADR に及ぶ（中身は変えない）

- 日付: 2026-11-20
- 出典: ADR-0036（[adr/0036-owner-not-hito.md](../adr/0036-owner-not-hito.md) 決めたこと 4。オーナー 2026-11-20 が「過去の記録も語だけ替える」を選んだ）
- 覆す: [2026-11-10-word-replacement-reaches-frozen-records.md](2026-11-10-word-replacement-reaches-frozen-records.md) のうち「今回の語だけが例外」（一部。役の名前の置き換えを例外に足す）と、ADR-0026 決めたこと 10・13 の「本文は当時の記録として残す」（一部。語の置き換えだけ）

役を指す「人」を「オーナー」に替える置き換えは、`docs/decisions.md` の凍結した表の行と、`docs/decisions/`・`docs/adr/` の古いファイルにも及ぶ。古い文書を読んだエージェントが「人」を真似ることを無くし、読み手が読み替えをしなくて済むようにするため。変えてよいのは語だけで、決定の中身・理由・捨てた案・番号・行の順は変えない。オーナーの発言の引用（「」の中）と、当時の識別子をバッククォートで写した所と、`docs/vision.md` は替えない。置き換えは、ADR の冒頭に索引を足す作業と大きい 6 本を畳む作業が済んでから行う。
