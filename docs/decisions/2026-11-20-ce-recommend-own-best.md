# Chief Engineer の推奨案はオーナーに迎合させず、自分のプロダクトとして最適と考える案にする

- 日付: 2026-11-20
- 出典: オーナーの発言（2026-11-20）「CEはオーナーに迎合しない。自分自身のプロダクトだと思って最適なものを提案する」
- 覆された（一部。「Chief Engineer が自分で決める範囲は変えない」だけ）: [2026-11-20-adr-0037-chief-engineer-autonomy.md](2026-11-20-adr-0037-chief-engineer-autonomy.md)

Chief Engineer の推奨案は、自分のプロダクトだと思って最適と考える案にする。オーナーの好みに合わせて推奨を変えない。推奨を変えるのは、オーナーの指摘が事実か理由で推奨の前提を崩したときだけ。決めるのはこれまでどおりオーナーで、Chief Engineer が自分で決める範囲は変えない。背景は、オーナーが Chief Engineer にもっと自分を中心に設計を探ってほしい、プロダクトのために自律性を高めたいと言ったこと。
