# ADR-0025: 課題の一生の規則と TLA+ のモデルを repo に置き、issue.yaml と照らして CI で確かめ続ける

- 日付: 2026-11-19
- 出典: ADR-0025（[adr/0025-formal-model-in-repo.md](../adr/0025-formal-model-in-repo.md)。Chief Engineer の課題 A-0008。オーナーが対話の中で決めた。元は人の発言 2026-11-19「Lean言語によるテストも用意してもいいんじゃないかと思った」）

課題の一生のモデルを TLA+ で書いて repo に置き、規則 6 本（R1〜R6）を検査器 tla-ts（版を固定。Java は要らない）で確かめる。Lean は今は入れない。状態の定義 `process/states/issue.yaml` は人が書くまま（ADR-0017 決めたこと 1 は覆さない）で、CI がモデルと 2 方向で照らし、食い違えば落とす。CI では秘密も権限も無い別の job で回す。課題の一生の動きを変える PR は同じ PR でモデルを直し、規則を弱める変更と「モデルの外」を増やす変更は人が見る。価値の仮説は置かない。モデルとコードを機械で照らすこと・残り 9 本の状態の定義・「いつか必ず」の形の規則は範囲の外。中身・理由・捨てた案は ADR が正。
