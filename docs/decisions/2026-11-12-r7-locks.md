# 手で 2 本打つ所に lock を足す（dispatcher・ゲート・chief-of-staff・boot）

- 日付: 2026-11-12
- 出典: 課題 A-0071・[ADR-0007](../adr/0007-interim-gap-inventory.md) の切る案 R7（A6・A7）・[dispatcher.md](../dispatcher.md) §7.3 の G1・G2・G5・G6 の「直すなら」

dispatcher.md §7.3 の G1・G2・G5・G6 を塞ぎ、§7.2 の #1・#4・#10・#13・#14 の「今の守り」へ移した。どれも `flock` のファイルで、プロセスが落ちれば OS が外す（消し忘れの lock は残らない）。

| lock | 置き場 | 取り方 | 取れないとき |
|---|---|---|---|
| `andon dispatcher`（G1） | 控えの置き場の `.dispatcher.lock` | 先頭で待たずに取り、終わるまで持つ（`--once` も） | 1 行出して 0 で終わる（もう 1 本が回している） |
| `andon gate`（G2） | 課題の `library/.gate.lock`（`gate/` の外。`wait` で記録の置き場を作らない） | PR を読む前から、記録を書いて PR に写し終えるまで持つ。`--dry-run` は取らない | 待つ |
| `andon chief-of-staff`（G5） | 控えの置き場の `<slug>.cos.lock` | 「数える→起動する→config.yaml に書く」の間持つ | 待つ |
| `andon boot`（G6） | `boot.json` と同じ置き場の `boot.lock` | 生成と起動の段の間持つ | 待つ |

ここで置いたこと:

- **dispatcher だけは待たずに終わる。** 係は常駐で、2 本目は回す意味が無い（`.terminal.lock` と同じ作り）。ほかは 1 回きりの命令なので、待ってから自分の分を済ませる。後の方は先の方が作ったもの（起動した Chief of Staff・生成した配布物）を見て、二重には作らない。
- **ゲートは「待つ間にほかの run が同じ head の記録を書いた」ときだけ、その記録を返して書かない・写さない。** lock で直列にしただけでは、後の run が先の記録を「同じ head で 2 度目」と読み、Must fix が残っていれば `needs_human` に上げて PR にもう 1 度付ける。重なったかは、記録の更新時刻が自分の run の始まりより後かで見る。間を置いて打ったゲートは今までどおり 2 度目として決め直す。
- **`andon chief-engineer` には足さない。** 課題を 1 つ起動するだけで、1 プロジェクト 1 人の決まりが無い（R7 の範囲の外）。
