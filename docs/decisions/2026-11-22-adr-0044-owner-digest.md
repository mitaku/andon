# ADR-0044: オーナーが読むダイジェストを定期に作り、Slack へ送る

- 日付: 2026-11-22
- 出典: ADR-0044（[adr/0044-owner-digest.md](../adr/0044-owner-digest.md)。Chief Engineer の課題。オーナーが対話の中で決めた。元はオーナーの発言 2026-11-21「ルーティーンでオーナーが理解をするための報告HTMLをSlackなどのコミュニケーションツールへ報告する」）

工場で起きたことを、オーナーが後から短い時間で理解できる 1 枚（ダイジェスト）にまとめ、kanban のルーチン `daily-digest` で毎朝作り、セルの外の Slack へ送る。読むだけの command が期間の記録を集め、担当が要旨とテーマを書き、command が依存の無い単一の HTML に組み立てて送る。数と一覧と図は command が描く。送り先はオーナーが `project.json` に書き、書いてあることを毎回の送信の許しとして扱う。設定の無いセルでは `files/` にだけ出す。オーナーを呼ぶ知らせを Slack へ出すことと、Slack から答えることは範囲の外である。中身・理由・捨てた案は ADR が正。
