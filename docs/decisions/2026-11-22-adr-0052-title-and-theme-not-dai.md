# ADR-0052: 「題」をやめ、タイトル・テーマと書く

- 日付: 2026-11-22
- 出典: ADR-0052（[adr/0052-title-and-theme-not-dai.md](../adr/0052-title-and-theme-not-dai.md)。Chief Engineer の課題。オーナーが対話の中で決めた。元はオーナーの発言 2026-11-22「題っていうのもAI語録っぽいので直しておきたいね」）

Andon の文から、熟語でない漢字 1 字の「題」を外す。課題や PR などの名前を指す所は「タイトル」、Chief Engineer が受け持つ検討の単位は「テーマ」と書く。「課題」「問題」「主題」のような熟語と、識別子は変えない。語の決まりは `writing.md` の 1 行と用語集の Chief Engineer の項に書き、用語集に新しい項は足さない。替える範囲は repo の全部で、ADR と決定の記録も語だけ替える。コマンドの出力の文も替え、古い語を読む両対応は置かない。語が戻らないことは語の検査で守る。中身・理由・捨てた案は ADR が正。
