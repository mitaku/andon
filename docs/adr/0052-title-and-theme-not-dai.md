- 状態: **決定（2026-11-22）**。オーナーが対話の中で「決めた」と言った。実装は「依頼書に切る案」のとおり別の課題（切るのは Chief of Staff）。覆すときは新しい ADR を書き、この行を「覆された → ADR-NNNN」に直す。小さな改めは「決めたこと」に下から足す。

## 前提（同意済み。番号）

オーナーは 2026-11-22 の入口で、言い直しと前提 1〜5 を 1 問で示され、会話での言い方を答えて、どの前提にも異を唱えなかった。

1. **困っているのは語そのもの。** yomiyasu の指摘の数ではない。
2. **意味が 2 つあるので、置き換え先の語も意味ごとに決める。** 1 語には揃えない。
3. **識別子としくみは変えない。** kanban の `title`、ダイジェストの `themes`、wiki の `topics/`、branch の名前の作り方はそのままにする。
4. **語の決まりを直すだけでは足りない。** skill、文書、コマンドの出力に語が残る限り、エージェントは書き続ける。文の中の語も替える。
5. **届け方は、これまでの語の置き換えと同じ。** パッケージのバージョンアップで各セルに届け、語が戻らないことを語の検査で守る。
