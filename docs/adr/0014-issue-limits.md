# ADR-0014: 任せきりの担当にターン数・時間の上限を掛ける（仕様・設計。2026-11-10。課題 A-0056）

## 問題（人の言葉で。言い直しの段落）

離席中や夜間に、人が見ていないまま流す担当（とレビュアー）が、止まらずに回り続けてターンと時間を食い潰すことがある。今の Andon には、課題ごとに「ここまで」という上限が無く、止まる仕組みは stalled（働き 20 分・idle 15 分）と提供元の使用量の上限だけ。欲しいのは、Chief of Staff が課題ごとにターン数・時間の上限を付け、担当がそこに当たったら黙って死ぬのでなく、途中までの報告と問いを台帳に残して止まり、人か Chief of Staff が続けるか・切り直すかを決められること。Claude Code の `--max-turns`・`--max-budget-usd` は print 専用で対話の担当には効かないので、フックで数えて止める形になる。費用（ドル）の上限はこの題から外す（人。2026-11-10。フックは費用を受けず、トークン数は A-0054 で測ってから）。
