## 前提（同意済み。番号）

オーナーが 2026-11-20 に 1〜5 に同意した。

1. **困っているのは語そのもので、指摘の数ではない。** 指摘を止めるだけなら、許可の一覧に語を書けば済む。それでは語が残るので採らない。
2. **用語集の項を消すだけでは足りない。** skill・文書・コマンドの出力が 3 語を使い続ける限り、定義の無い語が文に残り、エージェントは書き続ける。文の中の語も替える。
3. **識別子は変えない。** `kanban`・`ledger`・`gate`・`andon/gate`・`version` は機械が読む約束で、動いているセルの記録と食い違わせない。替えるのは日本語の文だけ。
4. **替える場所は、役の名前の置き換えと同じ。** repo の全部が対象で、ADR と決定の記録も語だけ替える。ビジョンの文書と図は替えない。セルの側は指針と wiki のページだけ直し、過去の依頼書と報告は直さない。
5. **流す順は、役の名前の置き換えのあと。** 残りの課題が同じファイルを広く書き換えるので、同じ場所の課題が済んでから流す。skill を触る PR をだれがマージするかは、gate がいまの条件表で決める。

## 決めたこと（番号・日付・誰が決めたか・理由・捨てた案。あとから覆したら上書きせず下に足す）

1. **2026-11-20 「台帳」「ゲート」「版」の 3 語を、Andon の文から外す。**（オーナーが決めた。Chief Engineer の推奨は「台帳」と「ゲート」の 2 語だけだった）
   用語集の項を消すだけでなく、skill・文書・コマンドの出力・コードのコメント・検査の文の中の語を、決めたこと 2〜4 の語に替える。
   理由: オーナーが選んだ（2026-11-20）。yomiyasu がパッケージの文で語を名指す指摘 148 件のうち、138 件がこの 3 語である（事実 5）。
   捨てた案: 2 語だけにする（Chief Engineer の推奨。「版」は用語集に項が無く、パッケージの文への指摘は 3 件だった）／用語集の項を消すだけにして、文の中の語は替えない（定義の無い語が約 3,400 か所に残る）／語は残し、yomiyasu に指摘させない（許可の一覧はほかのセルに届かず、語も減らない）／用語集の Andon だけの呼び名を全部見直す（題が大きくなり、3 語のほかは指摘の材料が少ない）。
2. **2026-11-20 「台帳」は、識別子のまま kanban と書く。**（オーナーが決めた。Chief Engineer の推奨どおり）
   プロジェクトごとの課題・問い・ルーチン・履歴のファイル群を、文の中で kanban と呼ぶ。裸の kanban はいつもファイル群を指す。それを読み書きするコマンドを指すときは、「kanban の CLI」か、バッククォートをつけた `kanban` と書く。
   理由: フォルダの名前も CLI の名前も既に kanban で、呼び名が 1 つになる（事実 7・8）。オーナーが自分で打つコマンドの名前でもある。hc や dispatcher と同じ形にそろう（事実 9）。
   捨てた案: 「カンバン」（トヨタ生産方式ではカード 1 枚を指し、用語集が課題の出典として「かんばん」と書いているので、意味がずれる）／「課題の一覧」（問い・ルーチン・履歴も入っているので名前が狭く、候補の一覧・パターンの一覧と紛れる）／ledger（コードと schema の名前だが、オーナーが打つコマンドの名前ではない）。
   これは `docs/design.md` §3.5 の「日本語の呼び名は『台帳』のまま」を改める（事実 10）。トヨタ生産方式のかんばんが課題に当たるという対応は、出典として残す。
   細部:

   | 今 | 直したあと |
   |---|---|
   | 台帳に書く、台帳を読む、台帳の課題 | kanban に書く、kanban を読む、kanban の課題 |
   | 台帳の CLI（`kanban`）、台帳の CLI | kanban の CLI |
   | 台帳（kanban）、`kanban`（台帳） | kanban |
   | 台帳の CLI は `kanban` | 文ごと消すか、「kanban を読み書きするコマンドは `kanban`」 |
   | 本物の台帳、偽の台帳、セルの台帳、仮設の台帳 | 本物の kanban、偽の kanban、セルの kanban、仮設の kanban |
   | コマンドを指す「本物の kanban」「偽の kanban」（今の検査の文） | 本物の kanban の CLI、偽の kanban の CLI |
   | 語の表の「**台帳** ｜ ledger」のように、日本語の語と識別子を並べた行 | 「**kanban** ｜ ledger」。語と識別子が同じになる行は、識別子の列を消すか 1 つにまとめる |
   | 流れの定義の表の語「台帳の CLI」（`internal/process/process.go`） | kanban の CLI |
