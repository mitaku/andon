# Security policy

Andon is an experimental, one-person project. There are no supported release lines; only the latest `main` (and the container image built from it) is maintained.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. This button exists only when the repository is public and the maintainer has turned the feature on.

If you cannot see **Report a vulnerability**, open an issue that only asks for a private way to report a security problem. Do not write any details of the vulnerability in the issue or anywhere else in public.

Include what is affected (file, command, or image tag), how to reproduce it, and the impact you expect. There is no fixed response time; reports are handled on a best-effort basis.

Secrets or personal values found in this repository or its history also count as vulnerabilities. Report them the same way.
